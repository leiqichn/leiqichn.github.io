1. NVIDIA/auto-ontology

语言：Python · 总星标：5,010 · 2,050 stars today

2. max-sixty/worktrunk

语言：Rust · 总星标：11,037 · 531 stars today

这是用 Rust 编写的 Git worktree 管理命令行工具，专为多个 AI 智能体并行工作的场景设计，适合需要同时推进多项开发任务的工程师。关注点是工作区管理与智能体工作流的结合；具体支持哪些操作、如何处理冲突，现有描述未说明。

3. mattpocock/skills

语言：Shell · 总星标：313,320 · 1,379 stars today

4. floci-io/floci

这是一个以 Java 为主要语言的 AWS 本地模拟器替代方案，适合关注云服务本地开发与测试的工程师。项目以轻量和永久免费为宣传点，值得进一步了解服务覆盖范围；但榜单未给出兼容性、资源占用或许可证信息，相关宣传不能直接视为已验证结论。

5. thedotmack/claude-mem

语言：TypeScript · 总星标：112,862 · 1,172 stars today

项目为智能体提供跨会话持久上下文：记录会话活动，经 AI 压缩后，将相关内容注入后续会话。适合长期使用编程智能体、希望减少重复交代背景的开发者。描述列出多种工具支持，值得关注记忆复用方式；数据保存位置、隐私机制与压缩效果尚不明确。

6. vercel-labs/agent-desktop

语言：Rust · 总星标：15,106 · 2,470 stars today

这是面向 AI 智能体的计算机操作命令行工具，主要语言为 Rust，适合研究桌面任务自动化和智能体工具接入的开发者。今日新增 2,470 星，显示出较高关注度；但描述十分简短，未说明支持的系统、操作范围或权限机制，实际能力仍需进一步确认。

7. github/spec-kit

语言：Python · 总星标：147,307 · 808 stars today

这是一个帮助用户开始采用 SDD 或其他流程的 Python 工具包，适合探索开发流程组织方式的工程师与团队。值得关注的是它以工具包形式辅助流程入门；不过描述没有展开 SDD 的含义，也未列出模板、命令或集成能力，无法据此判断与现有流程的契合程度。

8. The-PR-Agent/pr-agent

语言：Python · 总星标：14,759 · 280 stars today

项目定位为开源的拉取请求审查工具，主要语言为 Python，适合希望探索自动化代码审查的开发者与维护者。描述特别强调它并非 Qodo 的免费套餐，选型时值得留意这一身份区分；榜单未说明审查范围、平台支持及准确性，不能据此推断审查质量。

9. harry0703/MoneyPrinterTurbo

语言：Python · 总星标：138,969 · 617 stars today

项目通过 AI 大模型与自动化工作流，按主题或关键词生成高清短视频，主要语言为 Python。适合希望尝试视频制作自动化的内容创作者与开发者，关注点是从主题输入到视频输出的流程整合。榜单未提供成片示例、生成耗时、成本或素材来源，实际效果尚待确认。

10. garrytan/gstack

语言：TypeScript · 总星标：139,343 · 290 stars today

这是 Garry Tan 分享的 Claude Code 配置，包含 23 个带有明确实践偏好的工具，覆盖设计、工程管理、发布、文档和测试等角色。适合希望参考多角色协作方式的开发者。值得关注其角色分工，但角色名称并不代表已具备相应岗位的完整能力或可靠性。

11. FareedKhan-dev/kimi-k3-in-c

语言：C · 总星标：10,296 · 351 stars today

项目描述宣称用可移植 C99，让 2.78 万亿参数的 Kimi K3 在单颗 CPU、8.24 GB 内存下推理，且不依赖 BLAS、框架或 GPU。适合关注推理实现的开发者研究。该资源宣称值得核实，榜单未提供实现细节、速度或输出质量证据。

12. JiaFeiMiao-K-Cat/DiscImageStudio

语言：C# · 总星标：6,614 · 1,778 stars today

13. MichaelCade/90DaysOfDevOps

语言：Shell · 总星标：30,421 · 97 stars today

项目起初是作者的公开学习记录，后来发展为社区使用的结构化 DevOps 学习地图，内容涵盖原则、流程、工具与应用案例。适合希望建立知识框架的学习者，值得关注其三年积累和主题覆盖。榜单未列出具体课程安排、难度或更新情况，不能保证学习周期与成效。

14. D4Vinci/Scrapling

语言：Python · 总星标：96,544 · 2,005 stars today

这是一个 Python 网页抓取框架，描述覆盖从单次请求到完整爬取的任务，适合需要采集网页数据的开发者。值得关注的是不同抓取规模下的统一框架定位，今日新增 2,005 星。描述中的最佳属于宣传措辞，榜单未提供性能、站点适配或稳定性证据。

15. Thysrael/Horizon

语言：Python · 总星标：12,491 · 121 stars today

这是一个用 AI 构建个人新闻雷达的 Python 项目，可生成中英文每日简报，适合希望持续跟踪资讯的读者与开发者。值得关注的是个人新闻整理与双语简报的结合；榜单未说明新闻来源、筛选方式、摘要准确性或定制范围，尚无法判断具体的信息覆盖能力。
